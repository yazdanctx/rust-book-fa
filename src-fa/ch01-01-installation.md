قدم اول نصب `Rust`ـه.

برای مدیریت ورژن های مختلف `Rust` و کلا ابزار های مرتبط باهاش، یه ابزار تحت کامندلاین وجود داره به نام `rustup` که ما الان میخوایم بریم `Rust` رو باهاش نصب میکنیم.

> این `rustup` یک سری آلترنتیو هم داره: [روش‌های دیگه نصب راست][otherinstall]

حالا قبل اینکه وارد ماجرا بشیم، بذار اول یه توضیح بدم که هدف این چپتر چیه.

ما اینجا قصدمون اینه که آخرین نسخه استیبل `Rust compiler` رو روی سیستم عاملمون نصب کنیم، و `Rust` خودش یه سری تضمین ها به ما میده که هر مثالی که شما تو این کتاب میبینی، در آینده و با نسخه های جدید تر `Rust` هم کامپایل بشن.

حالا ممکنه خروجی بین ورژن های مختلف یه مقداری فرق کنه چون `Rust` مدام میاد سیستم مدیریت خطاهای خودشو بهبود میده و خلاصه اینکه شما هر نسخه `stable`ـی از `Rust compiler` رو نصب کنی، مثال های این کتاب مثل ساعت کار خواهند کرد.

### نحوه نمایش دستور های کامندلاین

تو این چپتر و کل کتاب، یه سری دستور بهت نشون میدم که داخل ترمینال اجرا میشن، و خطوطی که باید داخل ترمینال وارد کنی همشون با `$` شروع میشن، ولی شما نباید این `$` رو تایپ کنی!!

این `$` فقط نشون میده که دستور از کجا شروع میشه، یعنی خطوطی که با `$` شروع نمیشن معمولا خروجی دستور قبلین، و اینکه دستور های مخصوص `PowerShell` به جای `$` از `>` استفاده میکنن.

### نصب `rustup` روی لینوکس یا `macOS`

اگه از لینوکس یا `macOS` استفاده می‌کنی، یه ترمینال باز کن و این کامند رو بزن:

```console
$ curl --proto '=https' --tlsv1.2 https://sh.rustup.rs -sSf | sh
```

این کامند میاد یه اسکریپت دانلود می‌کنه و نصب `rustup` رو شروع می‌کنه و بعد `rustup` خودش میره
آخرین نسخه `stable` راست رو نصب می‌کنه.

ممکنه ازت رمز عبورت رو هم بخواد که اوکیه، بعد اگه نصب موفق باشه، این خط رو می‌بینی:

```text
Rust is installed now. Great!
```

بعد شما به یه برنامه ای احتیاج داری که `Rust` باهاش بتونه بتونه خروجی های کامپایلر رو داخل یک فایل بهم بچسبونه و در نهایت یه فایل اجرایی بسازه.

به این برنامه میگن `linker` و در واقع شما الان به یک `linker` احتیاج داری، اینجا بذار برات باز کنم که چه اتفاقی داره میفته:

ببین وقتی `Rust` داره کدت رو کامپایل میکنه، نمیاد زارت خروجی نهایی رو تولید کنه بلکه اول کد `Rust` به فایل های `object` ( مثل `.o` ) تبدیل میشه و بعد `linker` میاد این `object file` هارو به همراه `library` های لازم ترکیب میکنه و یه `executable` نهایی مثل `my_program` میسازه:

```text
Rust code
    |
    v
rustc compiler
    |
    v
object files (.o)
    |
    v
linker
    |
    v
final executable
```

بعد خب روی لینوکس این `linker` معمولا از ابزار های `GNU` مثل `gcc` یا `clang` میاد، من خودم روی `macOS` هستم و `clang` کارو در میاره واسم.

حالا اینارو برای چی گفتم؟ به این خاطر که شما شاید موقع بیلد کردن، خطای `linker` بگیری و در این صورت باید یه `C` نصب کنی چون این کامپایلر `C` معمولا همراه خودش یه `linker` هم نصب میکنه.

بعد اصلا این کامپایلر `C` نیازه چون من دیدم یه سری از پکیج های رایج `Rust` پشت صحنه به `C` وابسته هستن و برای کامپایل شدن به کامپایلر `C` احتیاج دارن.

روی `macOS` می‌تونی با اجرای این دستور کامپایلر `C` رو بگیری:

```console
$ xcode-select --install
```

کاربرهای لینوکس هم معمولا باید `gcc` یا `clang` رو نصب کنن.

مثلا رو اوبونتو می‌تونی پکیج `build-essential` رو نصب کنی. دیگه اگه رو لینوکس هستی خودت برو ریسرچ کن من حال ندارم توضیح بدم.

### نصب `rustup` روی ویندوز

روی ویندوز برو به [https://www.rust-lang.org/tools/install][install] و دستور عمل نصب `Rust` رو دنبال کن. بعد یه جایی وسط نصب ازت می‌خواد `Visual Studio` رو نصب کنی و این حرکت یه `linker` و کتابخونه‌های `native` لازم برای کامپایل برنامه‌ هارو بهت می‌ده.

اگه توی این مرحله کمک بیشتری خواستی برو اینجا:
[https://rust-lang.github.io/rustup/installation/windows-msvc.html][msvc]

دیگه بقیه این کتاب از دستورهایی استفاده می‌کنه که هم توی `cmd.exe` و هم توی `PowerShell`
کار می‌کنن. اگه جایی تفاوت خاصی بود بهت میگم که کدوم رو باید استفاده کنی.

### رفع مشکل

الان برای اینکه ببینی `Rust` درست نصب شده یا نه پاشو برو یه `shell` باز کن و این خط رو وارد کن:

```console
$ rustc --version
```

باید ورژن نامبر، هش کامیت و تاریخ کامیت آخرین نسخه `stable`ـی که منتشر شده رو توی این فرمت ببینی:

```text
rustc x.y.z (abcabcabc yyyy-mm-dd)
```

اگه این اطلاعات رو دیدی یعنی `Rust` با موفقیت نصب شده و اگه هم ندیدی، چک کن که راست توی `variable` سیستمی `%PATH%` هست یا نه، اینجوری:

توی `CMD` ویندوز:

```console
> echo %PATH%
```

توی `PowerShell`:

```powershell
> echo $env:Path
```

توی لینوکس و مک‌:

```console
$ echo $PATH
```

اگه همه اینا درست بودن و `Rust` بازم بازی در آورد، یه چند جا هست که میتونی بری کمک بگیری. توی
[صفحه کامیونیتی][community] ببین چطوری می‌تونی با بقیه `Rustacean`ها ( یه اسم مسخره که
روی خودشون گذاشتن ) در ارتباط باشی.

### به‌روزرسانی و حذف

دیگه وقتی `Rust` رو با `rustup` نصب کردی بعدش آپدیت کردن به نسخه جدید خیلی راحته.

از توی شل این اسکریپت آپدیت رو اجرا کن:

```console
$ rustup update
```

برای حذف `Rust` و `rustup` هم این اسکریپت حذف رو از توی `shell` اجرا کن:

```console
$ rustup self uninstall
```

### کار آفلاین با این کتاب

بعدا توی چندتا از مثالها ما از پکیجهای `Rust` خارج از لایبری استاندارد استفاده می‌کنیم.

بعد برای اینکه بتونی اون مثال‌ها رو کار کنی، یا باید اینترنتت وصل باشه یا از قبل اون دپندنسی هارو دانلود کرده باشی.

بنظرم همین الان دپندنسی هارو دانلود کن که بعد گیر نکنی. ( بعدا مفصل می‌گیم `cargo` چیه و هر کدوم از این کامندها چیکار می‌کنن. )
